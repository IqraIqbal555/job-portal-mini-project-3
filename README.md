💼 Job Portal — Mini Project 3

A complete, responsive, and interactive Job Portal Web Application built using HTML5, CSS3, and Vanilla JavaScript.

The project provides a modern platform where users can discover job opportunities, search and filter jobs, view detailed job information, save favorite jobs, apply for jobs, and manage their applications through a personal dashboard.

✨ Features

🔎 Dynamic Job Search

Users can search jobs dynamically by:

- Job title
- Company name
- Skills
- Location

Search results update without reloading the page.

🎯 Advanced Job Filtering

Users can filter jobs using multiple criteria:

- Job Category
- Location
- Job Type
- Experience Level
- Salary Range

A Reset Filters option is also provided.

↕️ Job Sorting

Jobs can be sorted by:

- Latest Posted
- Oldest Posted
- Highest Salary
- Lowest Salary
- Job Title

💼 Dynamic Job Listings

The application contains multiple job listings generated dynamically from JavaScript data.

Each job includes:

- Job Title
- Company Name
- Company Logo
- Location
- Job Type
- Experience Level
- Salary
- Required Skills
- Posted Date
- Short Description
- Apply Button
- View Details Button

🔍 Job Details

Users can view complete information about a selected job, including:

- Job Title
- Company
- Location
- Salary
- Job Type
- Experience Level
- Description
- Responsibilities
- Requirements
- Skills
- Benefits
- Application Deadline

📝 Job Application System

Users can apply for jobs through a professional application form containing:

- Full Name
- Email
- Phone Number
- Cover Letter
- Resume
- LinkedIn Profile
- GitHub Profile

✅ Form Validation

JavaScript validation checks:

- Required fields
- Valid email format
- Phone number
- Character limits
- Resume selection
- LinkedIn URL
- GitHub URL

The application is submitted without refreshing the page.

💾 Local Storage

Local Storage is used to persist important user data, including:

- Submitted applications
- Saved jobs
- Selected theme

Data remains available after refreshing the browser.

❤️ Saved Jobs

Users can:

- Save jobs
- View saved jobs
- Remove saved jobs

Saved jobs are stored using Local Storage.

📊 My Applications Dashboard

The dashboard dynamically displays submitted applications with:

- Job
- Company
- Applied Date
- Application Status

Users can also:

- View application details
- Delete applications

🌙 Dark / ☀️ Light Mode

The application includes a complete theme system.

The theme changes:

- Background
- Text
- Cards
- Buttons
- Navigation
- Forms

The selected theme is saved using Local Storage.

📱 Responsive Design

The website is designed for:

- Mobile devices — under 600px
- Tablets — 600px–1024px
- Desktop — 1024px+

Responsive design uses:

- Flexbox
- CSS Grid
- Media Queries
- Relative units
- Responsive typography

📭 Empty States

When no jobs match the search or filters, the application displays a clear message instead of leaving the page blank.

Example:

«No jobs found. Try changing your search or filters.»

🔔 UI Feedback

The application provides visual feedback for different states, including:

- Loading state
- Empty state
- Success messages
- Error messages
- Saved job notifications
- Application submission notifications

📄 Pagination / Load More

The Jobs section includes a dynamic mechanism for displaying additional job listings without manually creating separate HTML cards.

HTML5

Semantic HTML5 elements are used to create a structured and accessible application.

The interface is divided into logical sections such as:

- Header
- Navigation
- Main content
- Hero section
- Job listings
- Forms
- Dashboard

CSS3
